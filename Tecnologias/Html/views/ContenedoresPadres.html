Contenedores padres en html

Los contenedores padres en HTML son elementos que contienen otros elementos dentro de ellos. Estos contenedores ayudan a organizar y estructurar el contenido de una página web.

Ejemplos de contenedores padres

Div

El elemento <div> es un contenedor genérico que se utiliza para agrupar otros elementos y aplicarles estilos o scripts.

<div class="contenedor">
    <h2>Título dentro del div</h2>
    <p>Párrafo dentro del div.</p>
</div>
